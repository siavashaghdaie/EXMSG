================================================================================
API ENDPOINTS
================================================================================

GET /api/admin/dashboard
  Description: Returns core dashboard data
  Auth: Required (Bearer token)
  Response: Stats, recent users, top groups

GET /api/admin/users
  Description: Paginated user list with search
  Auth: Required (Bearer token)
  Parameters: search (optional), page (optional), limit (optional)
  Response: Users array, total count, pagination info

GET /api/admin/stats
  Description: Detailed system statistics
  Auth: Required (Bearer token)
  Response: Users, conversations, and message metrics
