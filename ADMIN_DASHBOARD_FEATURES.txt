USER SEARCH & MANAGEMENT
================================================================================

Search Fields:
  • Username      (e.g., "john_doe")
  • Display Name  (e.g., "John Doe")
  • Email         (e.g., "john@example.com")

Search Features:
  ✓ Case-insensitive search
  ✓ Real-time results
  ✓ Partial matching
  ✓ Multiple field search
  ✓ Special character support

Pagination:
  • 20 users per page
  • Previous/Next buttons
  • Page indicator (Page X of Y)
  • Automatic update on page change

User Display:
  • Avatar thumbnail
  • Display name or username
  • Email address
  • Online/offline badge
  • Green badge = Online
  • Gray badge = Offline

GROUPS & CHANNELS SECTION
================================================================================

Information Displayed per Group:
  • Group icon (#) with gradient background
  • Group name
  • Member count
  • Total message count
  • Last activity time (implicit in order)

Sorting:
  • By most recently updated first
  • Shows top 5 active groups

Example:
  [#] General
      125 members | 2,450 messages

  [#] Engineering
      89 members | 1,892 messages

QUICK STATS FOOTER
================================================================================

Last Updated
  • Shows current time
  • Updates on refresh
  • Format: HH:MM:SS AM/PM

Average Daily Activity
  • Messages per day
  • Calculated from weekly data
  • Formula: messagesThisWeek / 7

Engagement Percentage
  • Online users / Total users
  • Percentage format
  • Real-time calculation
  • Example: "1.97% online"

RESPONSIVE DESIGN
================================================================================

DESKTOP (≥ 1024px)
  • 4 stat cards in 1 row
  • Full sidebar visible
  • Maximum width content
  • All features visible

TABLET (768px - 1023px)
  • 2 stat cards per row
  • Sidebar visible
  • Adjusted spacing
  • Optimized layout

MOBILE (< 768px)
  • 1 stat card per row
  • Sidebar hidden (toggle)
  • Full-width content
  • Touch-optimized buttons
  • Stacked layout
  • Horizontal scroll for large tables
